# MFCL 0.0.9 预览版 — 页面迁移与滚动优化

这是 **GitHub 预发布版本**，用于体验和验证本轮 UI 优化，不是稳定版。
从 0.0.8 升级无需迁移用户数据；本轮没有修改用户实例、世界或光影配置。

## 主要变化

- 资源包、光影迁到 MFCL 自制浏览器，与模组共用固定行高的虚拟化列表。
  保留各自项目类型和 `mods` / `resourcepacks` / `shaderpacks` 安装目录。
- 按类别缓存浏览页；打开旧类别时直接初始化目标页，不再先加载无关的游戏版本页。
- 用按渲染帧推进的有界滚轮模型替代旧 3 ms 动画；反向滚动立即响应，切页后停止残留滚动。
  像素滚动、显式触控板手势、系统惯性、直接触摸和水平滚动保留原生处理。
- 修复来源切换后的旧分类、实例切换后的版本筛选残留，以及过期异步结果覆盖新选择的问题。
- 限制图标缓存，避免异步图片保留废弃单元格或覆盖已复用的图标。
- 移除嵌入设置/旧页面的卡片和选项列表阴影；避免同一节点叠加入场动画，遵循禁用动画设置。
- 独立新增源码使用 MFCL 署名；修改上游源码时保留原版权，并注明 MFCL 修改。

## 验证与性能说明

- Java + 实际 Rust 测试后端：**827 项，800 通过、27 跳过、0 失败**。
- 本轮 11 项新增测试全部通过，覆盖滚动模型、真实 JavaFX 控件事件传递、类别/目录映射、
  异步来源冻结、阴影作用域，以及三类浏览器各 10,000 条数据的列表虚拟化。
- 本次修改文件的 Checkstyle 通过。仓库全量 Checkstyle 仍有既存问题，不能视为通过。
- 合成测试中，相同 20 次滚轮输入的位置更新约从 993–994 次降为 76–78 次，
  单帧最多一次更新。**约 92% 是重复位置更新的减少，不是整体 FPS 提升。**
- 已检查模组、资源包、光影的真实 Modrinth 搜索与版本列表，以及游戏版本、整合包、Java 管理、
  版本隔离页面截图。世界页截图后被关闭，且来源请求缺少有效 CurseForge API key；
  因此不宣称整组页面烟测全部通过，也不宣称世界页在线结果已验收。

详细测试边界和方法见[页面性能验收记录](https://github.com/Y-fyan/MFCL/blob/v0.0.9/docs/mfcl-ui-performance.md)。

## 已知边界

- 游戏版本选择、整合包、世界、Java 管理、版本隔离及部分对话框仍沿用上游实现，后续逐步迁移。
- 本轮没有重新验收实时账号登录、游戏下载/启动、真实触控板或 Windows/macOS 运行体验。
- 继续仅内置 **Linux x86_64** Rust 后端；Windows/macOS 使用 Java 兼容路径。
- CurseForge 需要有效 API key；没有通过绕过认证来掩盖来源限制。
- 按现有项目内部研发与测试配置，沿用上游 Microsoft OAuth client ID；不扩大其授权用途。
- 校验下载文件请使用 `SHA256SUMS.txt`。本次不会替换旧版本资产，也不部署网站。
