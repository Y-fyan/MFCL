# MFCL 0.0.9 预览：页面迁移与滚动优化

本轮基于 `v0.0.8`，以 `v0.0.9` 预发布版本提供，不替换任何旧版本包。
独立新增源码使用 MFCL 版权头；改自既有源码的文件保留原版权，并注明 MFCL 修改。

## 已调整的边界

- 模组、资源包、光影共用 `MfmcAddonDownloadPage`：使用 MFCL 自制、固定行高的虚拟化列表，
  分别查询正确项目类型，并将下载交给原安装后端，目标目录分别为
  `mods`、`resourcepacks`、`shaderpacks`。
- 主工作区按类别缓存浏览器；重新进入相同实例不重复构造控件或启动搜索。
  切换实例时更新安装目标，清除不适用的版本/加载器筛选。
- 搜索输入防抖；类别选项更新不产生中间搜索；切换目录来源先清空旧分类。
  每次异步请求冻结来源，旧搜索、分类和详情回调不能覆盖新选择。
- 每个浏览器最多缓存 128 张图标；异步图标订阅不强持有废弃单元格，并检查单元格的当前 URL。
- 旧 `DownloadPage` 直接初始化目标类别，不再先创建无关的游戏版本页。
- `ScrollMomentum` / `FrameScrollSupport` 替换旧 3 ms `Timeline`。
  离散滚轮每个渲染 pulse 最多推进一次，限制累计位移、立即响应反向操作，停止长拖尾。
  像素滚动、显式手势、系统惯性、直接触摸和水平滚动保留原生处理。
  移出场景、不可见、拖动或到达边界时停止计时器。
- `ScrollPane` 在内容层接收冒泡事件：位于子控件之后、皮肤 viewport 之前，避免抢走
  子控件已消费的输入，也避免事件在到达外层处理器前被皮肤吞掉。
- 去掉嵌入页及设置内容里的旧卡片/选项列表阴影；不改变这些区域之外的弹窗阴影。
  页面入场动画不再在同一个节点上叠加，并遵循禁用动画的设置。

仍保留上游实现的主要区域：游戏版本选择、整合包、世界、Java 管理、版本隔离、
高级实例设置及账号/导入导出等对话框。本轮没有删除这些功能，也没有改动用户实例、世界或光影配置。

## 自动化验证

Linux x86_64，提供实际 Rust 测试可执行文件：

```sh
MFCL_NATIVE_TEST_EXECUTABLE="$PWD/mfcl-native/target/release/mfcl-native" \
  ./gradlew :HMCL:test :HMCLCore:test --no-daemon
```

结果：**827 项，800 通过、27 跳过、0 失败**。本轮 11 项新增测试均执行通过，包括：

- 30–240 Hz 下总滚动位移一致、有限输入、反向及突发位移限制；
- 真实 JavaFX 皮肤的滚轮处理、重复安装、原生像素输入、显式手势、场景移除及子控件消费事件；
- 三类内容的明确类型/目录映射；离线控件不会启动搜索；异步请求来源不可变；
- 每类浏览器装入 10,000 条数据，在两种宽度下实例化的列表单元格少于 40 个；
- 嵌入区域移除卡片效果，区域外卡片保留效果。

本次修改的 Java 文件通过 Checkstyle，`git diff --check` 通过。
这不代表仓库全量 Checkstyle 通过；原有短版权头、超长类等问题不在本轮处理范围。
实时账号、游戏下载/启动和 Windows/macOS 运行验收未在本轮重新执行。

## 合成滚动对比

以不可变的已发布 0.0.8 JAR 为基线，对比当前源码；JavaFX 21.0.8、软件渲染、
相同 1000×700 视口。每轮注入 20 个向下 40 px 的离散滚轮事件、间隔 50 ms，
观察 3 秒，每组 3 次取中位数。忽略非测试注入的鼠标/滚动输入。
列表包含 10,000 条固定行高数据；普通滚动容器使用 20,000 px 内容。

| 指标 | 旧 ScrollPane | 新 ScrollPane | 旧 VirtualFlow | 新 VirtualFlow |
| --- | ---: | ---: | ---: | ---: |
| 位置属性更新次数 | 994 | 78 | 993 | 76 |
| 单 pulse 最大更新次数 | 17 | 1 | 21 | 1 |
| 最后一次位移距开始，ms | 2992 | 1287 | 2988 | 1286 |
| 最终位移，px | 2690 | 800 | 2787 | 800 |
| pulse 间隔 P95，ms | 16.33 | 16.32 | 16.68 | 16.63 |

新实现消除了约 92% 的重复位置更新，并保持输入的 800 px 总位移；旧实现额外加速，
在观察窗口结束时仍未完全停止。由于滚动距离和持续时间也改变，不能把更新次数减少
直接解释成 FPS 或整个启动器性能提升 92%。这些测试也不能代替真实触控板、多平台及硬件渲染体验验收。

本机诊断脚本和原始记录位于 `/tmp/opencode/ScrollBenchmark.java`、
`/tmp/opencode/run_scroll_benchmarks.py`、`/tmp/opencode/mfcl-ui-bench/`；
它们是本地诊断材料，不是启动器运行依赖。
